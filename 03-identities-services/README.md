# Module 3: Identities & Services Hardening

This directory contains security requirements and policies designed to protect administrative identities, user credentials, and critical network service accounts in the Active Directory domain.

## Technical Hardening Controls

* **[Identities and Services Hardening Baseline](identity-hardening.md)**
  Detailed requirement focusing on domain security boundaries, Fine-Grained Password Policies (FGPP), offline Local Administrator Password Solution (LAPS) integration, Group Managed Service Accounts (gMSA) lifecycle management, and Kerberos delegation and encryption hardening (restricting RC4/DES, enforcing AES).
